    Sources¶

    What JATMP collects out of the box. Every source can be edited, disabled or removed under Settings → Sources, and any RSS / Atom feed, Bluesky or Mastodon account, X account, public Telegram channel or threat-intel query can be added there.

    Sources that a newer version adds to the built-in list join an existing install automatically when it starts, and a notification lists them. JATMP remembers which built-in sources it has already offered, so one you deleted does not come back. Add new built-in sources (or python manage.py seed-sources) adds every missing built-in source, deleted ones included.

    Topic filters¶

    Any news or social source (RSS, Telegram, X, Mastodon, Bluesky) can carry a topic filter (Filter in the source's Edit dialog), for example to keep only the cyber posts of a general news channel:

    • security keeps only entries about breaches, hacking, fraud, malware and the like (English and Indonesian terms). Used for the general technology sections of Indonesian outlets.
    • cyber is the stricter version for general news sections (national, economy, law). Words that are fine in a tech section mean something else there ("tabung gas bocor", "modus penyelundupan", a hijacked bus), so only unambiguous cyber and digital-fraud terms count (serangan siber, data … bocor, situs diretas, judi online, penipuan online, anti-scam…), plus anything the fraud rules recognise as a scam report.
    • fraud keeps only entries about a scam (the scam-type rules of the fraud analysis). Used for fact-checkers, whose feeds are mostly political hoaxes.

    Separately, a source can have the topic scam & fraud (also in the Edit dialog). It then shows on the fraud overview, and a single scam word is enough to file one of its entries under Other scam.

    Telegram¶

    Add a source of kind Telegram public channel with the channel's username or t.me link. By default JATMP reads the channel's public web preview (https://t.me/s/<channel>), which needs no account: 20 posts per page, older pages for a backfill (up to 3,000 posts per run). Posts keep their links, forwarded-from name, attached file names and view count; posts without text (a bare photo or sticker) are skipped.

    Channels that turned the web preview off, or a deeper backfill, need MTProto:

    1. pip install -r requirements-telegram.txt (Telethon).
    2. Create an application at my.telegram.org and enter its api_id and api_hash under Settings → Social (or TELEGRAM_API_ID / TELEGRAM_API_HASH).
    3. Run python manage.py telegram-login once. It asks for the phone number, the login code and the two-step password if set, and stores the session string (telegram_session).

    From then on Telegram sources use MTProto automatically; set Via to web or mtproto on a source to force one. Both ways produce the same item ids, so switching never duplicates posts. Only public channels are read: JATMP does not join channels, read private groups or post. Use a separate Telegram account, because the session string gives full access to it.

    Channels run by threat actors (hacktivist groups, leak and fraud markets) are not built in: they are renamed or banned often, and following one is an analyst's decision. Add them like any other channel.

    Scam and fraud sources¶

    Source What it adds
    FBI IC3 public service announcements US fraud warnings (election, investment, impersonation scams)
    CekFakta.com, Liputan6 Cek Fakta Indonesian fact-checks about scams (fake bank accounts, bansos links, job offers), filtered with the fraud topic filter
    ScamSniffer crypto phishing domains One item per day of newly listed wallet-drainer and fake-airdrop domains (GPL-3.0 list, published a week late). The domains are marked malicious on arrival, so they do not use enrichment quota. Backfill reaches back to May 2022

    Scam reports also come from the news, social and Telegram sources. See Scams and fraud.

    Account verification¶

    The Bluesky and Mastodon accounts listed above were verified active on 12 November 2026, with three exceptions: vxunderground.bsky.social has no posts yet, and Marcus Hutchins and MalwareHunterTeam rarely post on Bluesky (their main activity is on X; Marcus Hutchins is also on Mastodon). X handles cannot be verified without an API token. The Telegram channels and the scam & fraud sources were verified on 16 November 2026.
