Authentication

Create a key under Profile → API keys and send it with every request:

curl -H "Authorization: Bearer jatmp_xxxxxxxx_…" \
     "{{ base }}/api/v1/items?min_severity=60&limit=50"

Scopes: read for the endpoints below, export for the IOC feeds. Each key is limited to a number of requests per minute (HTTP 429 with Retry-After above it). Browser sessions work too.

Polling and sharing rules

List endpoints return next_cursor; pass it back as cursor for the next page. To fetch only new data, poll with since=<ISO-8601 UTC> (items: collection time; entities and IOCs: last seen).

Only data allowed by the sharing rules leaves JATMP: items up to the configured maximum TLP, never items from sources marked “not shared” (e.g. ANY.RUN), and third-party provider details only when an admin enabled them. Verdicts are JATMP's own consensus.

Blocklist for a firewall or proxy (one value per line):

{{ base }}/api/v1/feeds/iocs.txt?type=domain,url&verdict=malicious&since_days=30

STIX 2.1 and TAXII 2.1

STIX bundles: /api/v1/stix/bundle, /api/v1/stix/items/<id> and /api/v1/stix/entities/<id> (scope export). Items become report, families malware, actors intrusion-set, CVEs vulnerability, techniques attack-pattern and indicators indicator with STIX patterns and indicates relationships, all with TLP markings.

Read-only TAXII 2.1 server for SIEMs and TIPs. Discovery URL: {{ base }}/taxii2/, API root {{ base }}/taxii2/api/, collections indicators and reports. Authenticate with an API key (scope read) as a Bearer token, or with HTTP Basic using any user name and the key as password. Polling with added_after, limit, next, match[type] and match[id] is supported (match[id] filters within the returned page).
